XIAO ePaper Clock

A battery-powered 7.5″ e-paper desk clock built on a Seeed Studio XIAO ESP32S3, with weather and self-updating firmware.

What this is

Open-source firmware for a large-digit e-paper clock: it syncs time over NTP, shows local weather from OpenWeatherMap, and sleeps between updates to stretch a single-cell LiPo battery for weeks. The display only redraws every few minutes, so there's no backlight and no flicker — it looks like a printed page until the time changes.

The firmware checks GitHub Releases for new versions on its own and flashes itself overnight, so a device out on a desk somewhere stays current without ever being plugged into a computer again after the first setup.

Setting up a device

WiFi and the weather location aren't baked into the firmware — each device is configured once over USB:

  1. Press a button on the device (any of the three) to enter its maintenance window.
  2. Plug it into a computer with a USB cable.
  3. Open the setup page below in Chrome or Edge, connect to the device, and enter WiFi + location.
Open the setup page → Uses the Web Serial API — Chrome or Edge on desktop only, no Safari or iOS.

Source

Firmware, hardware notes, and build instructions live in the GitHub repository. It's an Arduino/PlatformIO project targeting the Seeed Studio XIAO ESP32S3 Plus driving a TRMNL-style 7.5″ UC8179 e-paper panel.
